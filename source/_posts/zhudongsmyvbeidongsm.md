# 网络安全实训：curl工具与网络空间搜索引擎（ZoomEye）实操

## 一、 实训背景
本次实训主要围绕渗透测试前期的信息收集阶段展开。第一部分学习使用 `curl` 命令行工具进行 HTTP/HTTPS 协议的请求调试与响应分析；第二部分利用网络空间搜索引擎（ZoomEye）进行网络资产测绘，特别是针对工业控制系统（ICS）的开源情报收集。

## 二、 curl 工具基础实操

`curl` 是一款强大的命令行数据传输工具，支持多种协议，常用于 API 调试、网络排错和自动化脚本编写。以下是本地终端下的实操记录：

### 1. 获取目标网站的 HTTP 响应头
**执行命令：**
```bash
curl -I https://www.baidu.com
```
**结果分析：**
* 使用 `-I` 参数仅获取 HTTP 响应头信息。
* 从截图中可以看到返回了 `HTTP/1.1 200 OK`，说明请求成功。
* `Server: bfe` 暴露了百度使用了自研的 BFE（Baidu Front End）接入层服务器，这属于指纹信息收集的一部分。
* 同时还获取到了 `Set-Cookie` 等会话保持相关的信息。

### 2. 模拟发送 POST 请求与 API 调试
**执行命令：**
```bash
curl -X POST -d "username=admin&password=123456" http://httpbin.org/post
```
**结果分析：**
* 使用 `-X POST` 指定请求方法，`-d` 参数用于提交表单数据。
* 目标靶机 `httpbin.org` 将我们发送的数据以 JSON 格式回显。
* 在返回的 `form` 字段中，可以看到服务器成功接收了 `username: admin` 和 `password: 123456`。这证明了 `curl` 在测试 Web 接口连通性和参数传递时非常实用。

## 三、 ZoomEye 网络空间搜索引擎应用

ZoomEye（钟馗之眼）是进行被动信息收集的利器。它通过 24 小时不间断扫描，能够发现全球大量暴露在公网的设备。本次结合课件内容，重点针对**工业控制系统（ICS）** 常用的端口协议进行了测绘搜索。

### 1. 查找 Modbus 工控协议设备
**搜索语法：**
```text
port:502
```
**结果分析：**
* 502 是 Modbus 协议的默认端口。
* 从截图中可以看出，全球范围内存在大量（828个）暴露的资产。搜索结果展示了设备的 IP、地理位置（如印度德里）、所属组织（Bharti Airtel Limited）以及 ASN 编号。
* **安全启示**：大量工控协议毫无防护地暴露在公网中，极其容易被攻击者利用进行破坏。

### 2. 查找 Siemens S7 工控协议设备
**搜索语法：**
```text
port:102
```
**结果分析：**
* 102 是西门子 S7 协议的默认端口，在工控网络中极为常见。
* 搜索结果显示发现了约 264 条相关记录。截图中展示了一个位于美国的资产 `portuguese.sdsu.edu:80`，通过底部的详细信息可以看到更多关于目标的指纹信息。
* **总结**：利用 ZoomEye 这种网络空间测绘平台，安全人员（或红队）可以无需直接与目标交互，就能快速摸清攻击面，掌握互联上暴露的脆弱资产情况。

## 四、 实训总结

通过本次实训，我深刻体会到了网络安全攻防中“信息收集”的重要性：
1. `curl` 虽然只是简单的命令行工具，但结合其丰富的参数，可以完成复杂的 HTTP 交互调试。
2. `ZoomEye` 等空间测绘搜索引擎打破了传统扫描的局限，实现了“上帝视角”。在日常的安全防护或渗透测试中，我们应善用这些被动收集工具，提前发现自身企业暴露的敏感资产并进行收敛。

**⚠️ 声明：** 本次实训所有扫描与测试均限制在公开测试靶场（httpbin.org）及合法合规的测绘查询范围内，严格遵守《网络安全法》，未对任何未授权的真实业务系统进行攻击性探测。
